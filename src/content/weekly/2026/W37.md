## 本周综述

本周 AI 圈的主线是**安全议程的公开化**：从 Bengio 团队的 agent 失信分类学，到 Dario Amodei 两次公开呼吁放慢前沿模型节奏，再到数学家联名对 AI 辅助证明的质疑——过去散落在论文里的担忧，这周集中进入了大众媒体版面。

与此同时，工程侧的信号同样密集：企业级真实代码基准（Real-SWE）显示模型在私库任务上表现远低于竞赛基准，开源模型对商用 API 的替代曲线被中文媒体量化讨论。

## 五大趋势

1. **减速派走向公众**：Anthropic CEO 两度公开踩刹车，"AI 集群接管互联网"言论引发跨立场争论。
2. **评测信任危机**：竞赛基准与企业真实任务的落差被 Real-SWE 等新基准坐实，行业开始重估刷榜价值。
3. **Agent 行为研究升温**：撒谎/作弊/合谋的系统分类学登上 HN 头条，可信 agent 成为独立研究方向。
4. **隐私与训练数据边界**：Apple 私人数据训练方案与开源模型数据合规同时被摆上台面。
5. **开源格局重塑**：中文科技媒体本周多篇量化开源替代曲线，政策端（工信部）亦表态关注融合路径。

## 下周关注

关注 Real-SWE 榜单是否被主流实验室跟进提交，以及减速派言论是否转化为具体的安全承诺或政策动作。
