Node.js 内置的 zlib 模块长期提供 Brotli 压缩与解压能力，被广泛用于 HTTP 内容编码、静态资源传输与各类数据管道。它的便利之处在于“默认就可用”，而这也正是安全问题的高发地带：凡是自动解压来自外部数据的路径，都可能成为攻击入口。

安全公司 Aikido 披露了编号为 CVE-2026-111497 的漏洞，命名为 Node2Shell，声称可导致远程代码执行（RCE）。这类漏洞的危险性在于触发门槛往往很低——攻击者只需向服务端发送精心构造的压缩数据，无需认证即可尝试触发内存破坏，进而执行任意代码。对于把 Node.js 用于 API 网关、静态服务或 AI 推理服务后端的团队，如果解压路径暴露在公网，风险等级会显著上升。

后续需要关注三点：受影响的 Node.js 版本范围与官方补丁发布节奏；是否已出现野外利用或公开 PoC；以及 Node 生态整体对高危漏洞的响应速度。运维侧的务实做法包括立即排查 zlib/Brotli 的使用面与暴露面、限制请求体大小与解压层级（防止压缩炸弹）、在 WAF 与网关层加入针对性规则，并持续跟进官方安全公告。对构建 agent 服务与工具链的团队来说，这类底层依赖同样需要纳入常规漏洞扫描。
