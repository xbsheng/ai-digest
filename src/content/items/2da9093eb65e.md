The Register 报道称，开源 AI 智能体项目 OpenClaw 的创建者透露，自己上个月在模型 Token 上的支出高达 1000 万美元。这一数字之所以引发讨论，是因为它把「agent 很贵」从一种笼统感受变成了可量化的账本：与聊天机器人一次交互只消耗一轮推理不同，一个自主 agent 完成任务往往需要数十乃至上百轮的思考、工具调用、结果校验与重试，Token 消耗随任务复杂度呈非线性放大。

从背景看，开源 agent 项目的热度在近一年急剧上升，开发者社区把它视为对抗闭源平台的路径之一。但开源的是代码，不是算力：模型推理依然要向 API 供应商付费，长上下文、多轮工具调用和高频重试都会直接推高账单。1000 万美元的单月支出，实际上折射出两层结构性问题。其一是成本结构失衡——agent 的智能程度越高，越倾向于「多想几步」，而这些额外思考全部按 Token 计价；其二是价值回收困难——开源项目本身难以直接向使用者收费，而重度用户往往是消耗算力最多的一方，容易形成「越受欢迎越烧钱」的倒挂。

这一事件可能推动几方面的变化：更激进的上下文裁剪与缓存复用策略、小模型承担大部分简单决策的分层架构、以及本地推理与云端 API 的混合调度。同时它也把「agent 经济性」推到台前——如果单个活跃用户的边际推理成本无法被其创造的收入覆盖，那么再惊艳的 agent 演示也难以规模化。后续值得关注的是，OpenClaw 是否会公开更细的成本拆分，以及业界是否会出现针对 agent 场景的按任务计价而非按 Token 计价的付费模式。
