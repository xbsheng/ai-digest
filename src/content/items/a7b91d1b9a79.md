据路透社报道，美国多家银行已经检测到未经授权的 AI 智能体访问客户账户的行为，并开始对第三方 AI agent 关闭访问通道。这一事件发生在「代理式金融」（agentic finance）快速升温的脉络中：过去一年，各类 AI 助手开始替用户比价、订阅、转账和管理账单，其运作方式往往依赖屏幕抓取、凭据代持或开放银行接口，而银行的风控体系原本是为「人」设计，并非为自动化的非人主体设计。

核心矛盾集中在三个层面。第一是身份与授权：当访问账户的不再是客户本人，而是客户委托的软件代理，银行难以确认这是真实授权、还是被钓鱼或提示注入操纵的代理。第二是责任归属：若 agent 执行了异常转账或泄露了账户数据，责任在用户、agent 开发者还是银行，目前缺乏清晰规则。第三是数据通道：不少第三方 agent 通过抓取而非官方 API 获取账户信息，既绕过费率与合规框架，也绕过了银行既有的异常交易识别。报道指出，银行方面已识别出未授权代理的访问痕迹，并采取了阻断措施。

后续值得关注的是，这一封堵是否会推动行业形成统一的「代理身份」标准——例如为 AI agent 颁发可验证的委托凭证、限定其可执行的操作范围与额度，并要求全程留痕。若缺乏这类基础设施，可能出现两种分化：合规银行只与少数经过认证的 agent 平台合作，而其余场景退回人工操作。对于正在押注代理式商务的创业公司而言，银行侧的准入将成为比模型能力更现实的增长瓶颈。
